# Foundry development

This project was built with the microsoft-foundry skill. Before working on or
answering questions about Foundry agents, read the microsoft-foundry skill first.
If you are in VS Code, read the vscode-microsoft-foundry skill first.

Follow `.github/copilot-instructions.md` for the repository's development rules.
Never package `bd_agreements/`, `outputs/`, credentials, or confidential artifacts
with hosted application code. `.agentignore` enforces the deployment exclusions.
